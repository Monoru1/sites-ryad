# Léna Marchetti — Demo premium

Landing page premium construite avec Next.js, TypeScript, Tailwind CSS et GSAP.

## Lancer en local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Netlify

Le projet est prêt pour Netlify avec `@netlify/plugin-nextjs` via `netlify.toml`.
